# svc 표본 설계서 (S-SEC-10 설계서 대조용)

### `digests`

| 열 | 형식 | 등급 | 보호 | 뜻 |
|---|---|---|---|---|
| `digest_id` | `uuid` | 내부 | 평문 | |
| `session_key` | `bytea` | 비밀 | 해시 | 쿠키 값의 SHA-256 |
| `blob_key` | `bytea` | 내부 | 평문 | 잡아야 함: 키 재료일 수 있는데 해시가 아니고 예외 표시도 없음 |
| `verify_key` | `bytea` | 공개 | 평문 | 이름 예외: 서명 확인용 공개키(비밀 아님) |

보관: 표본.

### `payloads`

| 열 | 형식 | 등급 | 보호 | 뜻 |
|---|---|---|---|---|
| `payload_id` | `uuid` | 내부 | 평문 | |
| `payload` | `bytea` | 비밀 | 암호 | 잡아야 함: 이름에 key가 없지만 bytea 암호(엔진 암호문은 text) |
| `chain_sha256` | `bytea` | 내부 | 평문 | 해시 사슬 값(통과) |

보관: 표본.
