# 인수 시험 담당 (2단계)

명세(`docs/spec/`)를 근거로 언어와 상관없는 HTTP·gRPC 인수 시험을 `acceptance/`에 만듭니다. 판정은 `docs/policy/gates.md` › ACC-01입니다.

- 시험은 외부 계약만 봅니다. 대상 주소·DB 연결은 환경 변수로 받습니다. 대상이 없으면 "건너뜀"을 분명히 출력하고 통과로 세지 않습니다.
- 실행기는 Rust crate(`acceptance/` 아래)로 쓰고 `#![forbid(unsafe_code)]`와 다섯 검사를 지킵니다. 워크스페이스 멤버 추가(`Cargo.toml`)는 바탕 담당과 맞춥니다.
- **먼저 C# 판에서 통과**시킵니다. C# 사본은 읽기 전용이므로, C# 판을 띄워야 하면 자기 작업 공간(TEMP)에 사본을 복사해 빌드·실행하고, 실행 기록(명령·대상 커밋·통과/실패 수)을 `acceptance/runs/`에 커밋합니다. C# 판이 시험을 통과하지 못하면 시험이 틀렸는지 명세가 틀렸는지 가려 명세 담당에게 알립니다.
- 다 쓴 커밋은 `acceptance/qa`에 검사를 요청합니다.
