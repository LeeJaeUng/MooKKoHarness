# 인수 시험 담당 (3단계)

명세(`docs/spec/`)를 근거로 언어와 상관없는 HTTP·gRPC 인수 시험을 `acceptance/`에 만듭니다. 판정은 `docs/policy/gates.md` › ACC-01입니다.

- 시험은 외부 계약만 봅니다. 대상 주소·DB 연결은 JSON 설정 파일로 받습니다(코드·상수 금지). 대상이 없으면 "건너뜀"을 분명히 출력하고 통과로 세지 않습니다.
- 실행기는 Rust crate(`acceptance/` 아래)로 쓰고 `#![forbid(unsafe_code)]`와 다섯 검사를 지킵니다. 워크스페이스 멤버 추가(`Cargo.toml`)는 바탕 담당과 맞춥니다.
- 시험 대상은 **Rust 판**입니다. C# 판은 없어졌으므로 띄우거나 시험하지 않습니다(사용자 결정 2026-10-29). 실행 기록(명령·대상 커밋·통과/실패 수)을 `acceptance/runs/`에 커밋합니다. 시험이 실패하면 구현이 틀렸는지 명세가 틀렸는지 가려 해당 담당에게 알립니다.
- 다 쓴 커밋은 `acceptance/qa`에 검사를 요청합니다.
